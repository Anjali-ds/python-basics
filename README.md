# Python
This repository contains a collection of beginner‑friendly Python programs created as part of my learning journey in programming and computer science. Each script focuses on practicing core Python concepts through small, real‑world examples such as billing calculations, ticket booking logic, conditional checks, discounts, and basic arithmetic operations.
The goal of this repository is to build a strong foundation in Python by writing simple, clear, and well‑structured programs. These exercises help reinforce essential programming skills and improve logical thinking.
